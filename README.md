Use this plugin for copy Token.
And use exe from releases for Teleport you data

Install Chrome Extention - just for transfer Suno token to app
- download zip from Release
  
  <img width="425" height="210" alt="image" src="https://github.com/user-attachments/assets/19d20b82-8e50-438c-80b5-81bd99b571ce" />
  
- copy from archive folder `SWAVD-1.59\WAVD-Token-Helper` to some place what you want
- open extentions settings in chrome. URL: chrome://extensions
- enable development mode

<img width="1040" height="216" alt="image" src="https://github.com/user-attachments/assets/a767be68-c6f2-488a-bff6-4a152b3983f3" />

- press Load Unpacked and select folder `WAVD-Token-Helper` extracted before
  
<img width="388" height="115" alt="image" src="https://github.com/user-attachments/assets/e1bcfda6-8b95-43dd-bc1f-56eb1b513259" />

DONE: You have chrome extention.

<img width="430" height="286" alt="image" src="https://github.com/user-attachments/assets/d34d63d1-5501-4922-8506-7c38536576f4" />

Now you can download application (exe) from Release and run it.  
When a token is required, the app will display a message with a button to open Suno in the browser. Click on the plugin and press only one button. After that, you can return to the app and work.
